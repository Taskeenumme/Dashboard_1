# Dashboard_1
Power BI Sales Performance Dashboard

1. 📊 Project Overview

The Sales Performance Dashboard is an interactive Power BI report that provides a comprehensive overview of business sales metrics. It helps stakeholders monitor key performance indicators (KPIs) such as Total Sales, Profit, Quantity Sold, and Profit Margin, enabling data-driven decision-making and performance optimization.

2. 🧰 Tech Stack

* Power BI Desktop – Data visualization and report building
* Microsoft Excel – Primary data source (sales dataset)
* DAX (Data Analysis Expressions) – Used for calculated measures and KPIs
* Power Query (M Language) – Used for data cleaning and transformation

3. 💾 Data Source

* File Type: Excel Workbook (`.xlsx`)
* Contents: Sales transaction data including order details, customer info, product categories, shipping modes, and regional data.
* Connection: Imported directly into Power BI for modeling and analysis.

4. 📈 Key KPIs

* Total Sales – Sum of revenue across all orders
* Total Profit – Net profit from all sales transactions
* Quantity Sold – Total number of items sold
* Profit Margin – Ratio of profit to sales, expressed as a percentage

5. 📊 Visualizations

1. Sales by Region (Map): Geographic view of sales distribution across regions.
2. Sales vs Profit by Category (Bar Chart): Comparison of sales and profit across product categories.
3. Top 10 Customers by Sales (Table): Highlights the most valuable customers based on sales volume.
4. Monthly Sales Trend (Line Chart): Displays sales performance over time to identify seasonal trends.
5. Profit by Sub-Category (Tree Map): Shows profit contribution by product sub-categories for better product-level insights.

6. 🎚️ Filters and Slicers

Interactive slicers allow users to customize their analysis:

* Year
* Region
* Category
* Ship Mode

7. 🚀 Features

* Dynamic filtering and drill-through capabilities
* Clean, user-friendly design for quick insight extraction
* Real-time KPI cards with color indicators
* Optimized data model for efficient performance

8. 🧩 Future Enhancements

* Add forecasting for sales and profit trends
* Integrate additional data sources (e.g., CRM, ERP systems)
* Publish to Power BI Service for real-time sharing and updates

9. 🏁 Conclusion

This dashboard serves as a valuable business intelligence tool, offering a clear, interactive view of company sales performance and profitability. It empowers managers and analysts to identify trends, evaluate performance, and make data-backed strategic decisions.
